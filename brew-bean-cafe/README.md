# Brew & Bean — демонстрационный сайт кофейни

## Запуск
1. Распакуйте папку проекта.
2. Откройте `index.html` в современном браузере.
3. Для удобной разработки откройте папку в Visual Studio Code и запустите `index.html` через расширение Live Server.

Интернет нужен для загрузки фотографий с Unsplash и шрифтов Google Fonts. Внешние платные библиотеки и API не используются.

## Перед публикацией
- Замените демонстрационный адрес, телефон и email на реальные.
- Проверьте цены и меню.
- Убедитесь, что ссылки на изображения доступны; при необходимости скачайте изображения в локальную папку проекта.
- Проверьте сайт на телефоне и компьютере.
